# Baseline audit

Проверено 17–18 ноября 2026. Baseline: `f9ba71057c704e2698b31ace83b306df8b3d6dd9`. Рабочая ветка `feat/commercial-magazines`. До работы checkout чистый. AGENTS.md в репозитории не найден.

Стек: статические HTML/CSS/JS, GitHub Pages, PageFlip CDN для world/dreams, PDF.js CDN для art. Сборка и тесты отсутствовали. Последнее изменение добавляло блок отелей и mailto-форму.

| URL | Назначение | Решение |
|---|---|---|
| `/` | Общая презентация и mailto-форма | Новая B2C-главная; исходный HTML сохранён как `/legacy.html` |
| `/world.html` | 20 страниц «Мой путь» | Сохранить |

| `/assets/` и архивы | Исходные страницы / PDF / ZIP | Все сохранены |

Проблемы: форма открывала почтовый клиент и не сохраняла лид; общий оффер смешивал B2C/B2B; декоративная обложка вместо реального образца; нет FAQ, серверной валидации, обработки сетевых ошибок, локальных тестов; название журнала на главной расходилось с обложкой. Большие исходные WebP увеличивали вес.

В новой версии: отдельный B2B-маршрут, реальные цифровые страницы с подписью, оптимизированные копии WebP, независимый API и приватная БД, безопасно отключённая production-форма до настройки. Исходные материалы не выдаются за фото печатных экземпляров.

Риски: нет доступа к серверу/домену API; нет утверждённой политики журналов; нет фото физических экземпляров; нет цены индивидуальной работы; старые просмотрщики зависят от CDN. Публичные архивы уже существовали и не удаляются.
