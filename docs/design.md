# Визуальная система

## Два направления

A — «Личная редакция»: тёплая бумага, тёмный текст, бордовый акцент, крупная антиква, тонкие линии, цифровые страницы на шалфейном поле. Выбрано: соответствует содержимому существующих журналов и не требует фиктивной фотосессии.
B — «Современный фотоархив»: холодный белый, чёрный гротеск, плотная сетка, контрастные обложки. Отложено: лучше подошло бы каталогу/конструктору с большим набором продуктов.

| Основной вертикальный шаг | 88 desktop / 56 mobile |
| Кнопки | минимум 50 px высота; без капсул |

Два типографических назначения без внешних шрифтов и сетевых зависимостей. На мобильном один столбец. Focus outline 3 px, prefers-reduced-motion; картинки имеют alt, декоративная подложка пустой alt.

Активы — только исходные страницы проекта. В `assets/site/` созданы сжатые копии для лендинга; оригиналы в assets/world и assets/kids не менялись. Рендер обложек не обозначается фотографией печати. Фото готовых изделий — отдельная следующая задача.

Реализованные адаптивные макеты: index.html и hotels/index.html. Скриншоты 320/390/768/1440 в docs/screenshots; две страницы в iframe фиксированной ширины, а не эмуляция мобильного устройства.
