# Следующая итерация

P0: согласовать сервер и оператора/политику; развернуть API с приватным volume, HTTPS и backup; настроить уведомления и ответственного; проверить две заявки на production и чтение менеджером. Затем включить форму.

P1: реальные фото обложки, бумаги, разворота и журнала в руках; утверждённые комплектации/прайс/сроки; 5–7 интервью; разрешённые кейсы и отзывы. Выбрать аналитику и согласие. События уже подготовлены: view_example, cta_click, form_start, lead_submit_success, lead_submit_error, hotel_cta_click. Они не содержат PII и пока не отправляются провайдеру.

Первые две недели после запуска: посетители по источнику → просмотр примера → начало формы → сохранение → квалифицированный лид → ответ → согласованный заказ. Для отеля добавить встречу/пилот. Не назначаем выдуманные цели конверсии. Отмечать причины потерь и время первого ответа; назначить человека на ежедневный просмотр new-заявок.

P2: только после данных — калькулятор, расширение портфолио, автоматизация CRM, мультиязычность. Оплата и личный кабинет в MVP не входят.

Не запущены автоматические рассылки, платные сервисы или фоновые напоминания.
